### Building Intelligence.

Inmercity Labs is an AI and software lab building intelligent systems for businesses. We combine AI engineering, software development and product thinking to create agents, automation, platforms and digital products built for the real world.

Based in Barranquilla, Colombia. Building for companies anywhere.

---

### What we build

| | |
| --- | --- |
| **AI Agents** | Agents that do the work: internal agents, copilots, specialized assistants and multi-agent systems connected to the tools a business already uses. |
| **Intelligent Automation** | Manual, repetitive processes turned into systems: integrations, workflows, document processing and back-office operations. |
| **Platforms** | Complete digital platforms: web applications, SaaS, internal tools and AI-native products. Built to become infrastructure. |
| **Labs** | Prototypes, proofs of concept, applied research and our own products. Where the next thing starts. |

### How we build

1. **Intelligence by design.** AI is considered from the architecture, not added at the end.
2. **Build for production.** An impressive demo means nothing if it can't run reliably.
3. **Humans stay in control.** We automate work without losing traceability, judgment or human oversight.
4. **Simple on the surface. Powerful underneath.** Complexity belongs to the system, not to the user.
5. **Experiment fast. Engineer carefully.** We prototype quickly and build production with rigor.

### Stack

`TypeScript` `Next.js` `Python` `Supabase` `PostgreSQL` `Anthropic API` `n8n`

We pick tools for the problem, not the other way around. Data architecture gets validated before a single migration is written.

### Two engines

**Client Systems** — technology built for other organizations: agents, automation, platforms and AI infrastructure.

**Inmercity Products** — products, experiments and intellectual property developed in-house. The public repositories in this organization are where that work shows up.
